# research-data

Written by the archive collector (GitHub Actions → **Archive collect**, or the Data tab on a writable server).
Committed so a read-only deployment can show it. Nothing here is approved: documents are a catalogue of what was
read (metadata only), `research-staging/<club>/` is the export the club file reads as **unreviewed** rows.

- `research/<club>/archive-docs.json` · `archive-checkpoints.json` · `archive-endpoints.json` · `archive-runs.json` · `runs/<id>/`
- `research-staging/<club>/` manifest · sources · backlog · season-coverage (approvedForProduction 0)
