# מפת מוכנות הפיצ׳רים
הסטטוס מתייחס לחומר המצורף בלבד: כל הרשומות ב־staging ודורשות סקירת עורך. לא הוכחה מוכנות מלאה של אף פיצ׳ר.

| אזור | מה נאסף | מה נדרש להשלמה |
|---|---|---|
| מאגר שחקנים / XI / Blind Cow | שמות, תקופות ותפקידים חלקיים; נתוני מקור לאל־אהלי ולווידאד | עמדות לאל־אהלי ולווידאד, זהויות וכפילויות, נוער מול בוגרים, תקופות ועברית/אנגלית |
| Royal Rumble | מועמדי שחקנים בלבד | תמחור ודירוג אישי מבוסס, זכאות ועמדה לכל שחקן; אין מחירים בחבילה |
| משחקים / Archive / Timeline | תוצאות בשלוש עונות, משחקי עבר ורשימות אליפויות | סיווג לכל משחק, כיסוי עונות נוספות, משחקים מלאים וסתירות |
| Historical Lineup | רשומות דרבי קהיר ושני הרכבי ראג׳ה בגמר 1999 | פתרון זהות, אימות הרכב מלא ומבנה/מחליפים, מקור נוסף |
| Goal Reconstruction | מבקיעים ודקות בדרבי 2019 ושני שערים בגמר 2013 | תנועה, נקודת התחלה, מסירה/דריבל, וידאו וזכויות; מספר שערים אינו שחזור |
| Trivia | תוצאות, היסטוריה ותארים | כתיבה, מסיחים, ראיות ושאלות מאומתות ובדיקה חוצת מקורות |
| Memory / Kits | קטלוג מקורות לחולצות | חילוץ מדויק, אימות שנים, איורים/נכסים מורשים |
| Rivalry / polls | שני דרבים וסיפורי שלושת המועדונים | תוכן, שאלות וסקירה תרבותית; סקרים תלויים גם בקהילה |
| LIFE / Away Days / City | הצעות מסלול ומקורות על תרבות אוהדים | מחקר מקומי, תחנות, 21 פרקים וסיפורים, כתיבה וביקורת |
| Sharing / Collections / Challenges | ישויות בסיס | מיפוי למוצר בפועל, נכסים מורשים, בדיקות פונקציונליות |

אין להציג כאילו כל שחקן, כל תואר או כל אירוע אומת. מידע חסר הוא חסר, אין לנחש. בדיקת זכויות של מקור או תמונה היא תנאי לשימוש, וקישור למקור אינו רישיון.
