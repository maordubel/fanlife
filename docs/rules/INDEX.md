# FAN LIFE — rule index

One file per rule. Numbers are stable: code comments and tests that say "rule 104" mean `docs/rules/104.md`.
Before a task, find the area you are about to touch and read the rules listed under it. A rule records a decision of the owner or a lesson that cost a broken build, so it outranks your own taste.

Adding a rule: write `docs/rules/<next number>.md` and add one line here under its area. This file merges as a union, so parallel pull requests can each add a line.
