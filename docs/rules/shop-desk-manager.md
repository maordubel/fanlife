# Shop desk: one product manager (owner, 15.11.2026)

- The Products tab is one searchable list of every product (personal prints excluded): search, club, category, state (in the shop / made, hidden / not on sale / soft / on sale / fan favourite), sort (newest, name, price, sharpest, best selling), and "one row per design".
- Ticking rows (or select all) opens one bar for the lot: show, hide, a category in or out, rewrite listings in Printify, press, delete (asks first). Bulk work goes through the same desk actions as one product.
- A row opens the editor beside the list (a sheet on a phone): name and description (saved and sent to Printify), categories, shown, fan favourite; the first picture (any mock-up — the owner's choice is kept first by the hourly check-up while Printify still draws it); the print; "the same design on more products" (drafts beside it, pressed at once).
- "Bring in from Printify" joins products made straight in Printify, so everything is managed in one place; it changes nothing there.
- The storefront has a search box (`/shop?q=`): every word must be in the name, the club, the category or the description.
