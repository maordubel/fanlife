## 112 · LEGENDS MANAGER plays live, click by click (12.10.2026)

Owner: "click by click, less scrolling · round 1 with no transfers, a popup for the season tickets and the budget, a window after round 2 and again before the second half · watch the match live, not knowing the score · changes at half-time, 60′ and 75′ · a captain, +3%, without the player knowing · see the other clubs' squads".
1. **Schedule** (`LEGENDS_RULES.earlyWindowAfterRound`): draft → `board-grant` popup (season tickets, budget) → rounds 1–2 with the drafted squad → window after round 2 → window at halfway. A four-club league skips the round-2 window when halfway is the next round. Every season, not only the first. `view.nextWindow` says when.
2. **Engine 2** (`ENGINE_VERSION='legends-engine-2'`): a live match stops at exactly 45′, 60′, 75′ (`touchlineStops`); a snapshot from engine 1 keeps its old stops and no captain. `match-finish` passes every stop left with no change. The quick sim and an untouched live match still write one log.
3. **Captain** (`lineup.captain`, `captainOf()` falls back to the eleven's most-starred man; AI sides the same): his quality, attack and defence count ×`captainBoost` (1.03). No screen names the number — `tests/legends/rulebook.test.ts` reads the UI files for it.
4. **Live = the server's stop, never ahead of it:** `view.live.reel` (`kits.ts → liveReel`) holds the moments so far; `Theatre segment={from,to,outro}` plays only the part since `prevStop`; the final part plays from `last.reel`, then the full-time panel. The score, toasts and table stay hidden while watching.
5. **Popups are `components/legends/Sheet.tsx`**, portalled to `<body>` with the career's tokens and livery copied (a transformed page wrapper would otherwise pin `position: fixed` to itself); the save bar is portalled too. Night sheets = club news, paper sheets = choices. Animated buttons animate box-shadow, never transform (a moving target is never "stable").
6. **Other squads:** `view.clubs` (names, lines, stars, years, apps, goals, last XI) — never a hidden rating; the table and the ticket open `ClubSheet`.
