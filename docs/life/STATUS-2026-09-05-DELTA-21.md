## 5. לפני/אחרי — משחק אצטדיון אחד (גמר הגביע 26.5.1999)

**לפני (דלתא 20):** כניסה לרמת גן → כרטיס מקום → שיחה: שלוש שורות נרטיב על תשעים הדקות
("הם קודם. אתם אחר כך. השוויון… הארכה… השופט מסתכל בשעון") → פנדלים (בחירה) → סיום. אין לוח,
אין דקה, אין קהל שמשתנה, קריאה בלבד.

**אחרי (דלתא 21), מהפרוב:** לוח `בית"ר ירושלים 0 · המשחק · הפועל תל אביב 0` → "להרים את הצעיף /
להצטרף לשיר / להסתכל על הצד השני" → **0:1 להם** (AFTERMATH, אנחה) → "לדחוף קדימה / להישאר /
יד על הכתף" → BUILDING_TENSION → NEAR_MISS → **1:1** (GOAL_BURST, הבזק, רעד, נייר) → `הארכה` →
`פנדלים` → הפנדלים כבחירת נוכחות (כמו קודם) → `סיום 1:1` → "קובי יזכור את זה" → הסיום.
41 שניות של שעון + 3 פעולות. הלוח נסגר על תוצאת הארכיון.
