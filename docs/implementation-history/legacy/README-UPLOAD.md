# The Worker — הריפו המלא

זה **כל האפליקציה**, לא דלתא. אין פקודות להריץ ואין קבצים למחוק.

## מה לעשות

העלה את התוכן של התיקייה הזאת לגיטהאב, כרגיל. זה הכל.

Vercel יבנה לבד. אם יש קבצים ישנים שנשארו אצלך בריפו — הם **נדרסים** על ידי הקבצים
שכאן, וכולם תקינים. שום קובץ ישן לא יכול יותר להפיל את הבילד.

## למה הבילד נפל, ולמה זה נגמר

`app/kits/build/KitChallengeBoard.tsx` הוחלף ב-`KitRun.tsx`, אבל הוא נשאר אצלך בגיטהאב
ועדיין ייבא `submitKit` — פונקציה שכבר לא קיימת. Vercel בנה אותו ונפל. אצלי הכל היה
ירוק כי אצלי הוא היה מחוק.

ביקשתי ממך למחוק אותו בפקודה. **זה היה פתרון גרוע** — אתה מעלה לגיטהאב, לא מריץ shell,
והעלאה דרך הדפדפן מוסיפה ודורסת קבצים אבל לא מוחקת אותם. אז גם אם הייתי מבקש עשר פעמים,
הקובץ היה נשאר.

הפתרון האמיתי: **כל קובץ שפרש הוא עכשיו "מצבה"** — קובץ תקין וריק שמסביר במה הוחלף.
הוא מתקמפל תמיד, לא מייבא כלום שיכול להישבר, ואף אחד לא צריך למחוק אותו.

שש מצבות בעץ הזה:

| הקובץ הישן | הוחלף ב־ | מה הוא עכשיו |
|---|---|---|
| `app/kits/build/KitChallengeBoard.tsx` | `KitRun.tsx` | re-export תקין |
| `app/trivia/TriviaRound.tsx` | `TriviaRun.tsx` | נמחק (לא היה שבור) |
| `app/trivia/summary/page.tsx` | הריצה נגמרת במקום | **הפניה ל-`/trivia`** — כל קישור שיתוף ישן עדיין עובד |
| `app/trivia/summary/ShareCard.tsx` | `components/share/ShareRow.tsx` | ריק ותקין |
| `components/press/StoryCard.tsx` | `lib/share/story.ts` | ריק ותקין |
| `app/derby/BlackFile.tsx` · `actions.ts` | `app/derby/file/` | ריקים ותקינים |

`tests/guards.test.ts` בודק שכל מצבה קיימת, קצרה, ולא מייבאת שום דבר שיכול להישבר.
אם מישהו יחזיר לשם קוד אמיתי — הטסט ייפול.

## מה נבדק לפני האריזה

- `npm run typecheck` — נקי
- `npm run test` — **230 טסטים עוברים**
- `npm run build` — ירוק
- **שחזרתי את הקובץ השבור שלך לתוך העץ הזה, ראיתי את אותה שגיאה בדיוק, החזרתי את המצבה,
  והבילד עבר.** זו לא הבטחה — זה מה שקרה במכונה.

## הרצה מקומית (אם בא לך)

```
npm install
npm run dev
```
