# גיליונות המקור — ספטמבר 2026

חמישה־עשר הגיליונות שמהם נחתך כל מה שנשלח ב-ZIP הראשי.
**לא חובה להעלות אותם כדי שהמשחק יעבוד** — כל הנכסים כבר חתוכים ומוכנים ב-`public/life/art/`.

הם כאן כדי ש-`scripts/life/ingest-2026-09.py` יוכל לרוץ שוב: לזוז חיתוך בחצי אחוז,
להוציא חפץ נוסף מהגיליון, או להחליף רקע — בלי לבקש ממך שוב את הקבצים.

```
WORKER_ART=brand/source/life-2026-09 python3 scripts/life/ingest-2026-09.py
WORKER_ONLY=props python3 scripts/life/ingest-2026-09.py   # רק החפצים
```

מפוצל לשני חלקים בגלל מגבלת גודל. גרור את שניהם לשורש המאגר, בכל סדר.
