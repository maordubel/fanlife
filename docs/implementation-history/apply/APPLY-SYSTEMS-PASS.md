## מה צריך לעשות ידנית

1. **להעלות את כל התיקיות מה-ZIP** לשורש הריפו `maordubel/The-Worker`.
2. **למחוק בקליקים את התיקייה `lib/ingest/`** (שלושה קבצים: `dedupe.ts`, `guards.ts`,
   `types.ts`). אלה שאריות מהעלאה ישנה שמפילות את `npm run test` ואת `npm run typecheck`
   — הן היחידות שנשארות אדומות אחרי הדלתא הזאת. הבנייה בוורסל תקינה גם בלעדיהן,
   אבל כל עוד הן שם, שתי בדיקות נכשלות.
3. **שמירות קיימות ממשיכות לעבוד.** `SAVE_VERSION` עלה ל-3 וקובץ בגרסה 2 נקרא כמו
   שהוא. אין מה לאפס. (אם בכל זאת רוצים לראות פתיחה נקייה — הכפתור "התחלה מחדש"
   מתחת למסך.)
4. **אופציונלי, כשיהיה נוח:** להעלות את 46 קובצי ה-PNG שחסרים בריפו — כל סדרת
   `soldier-*`, `sinai-*`, `tikva-*` ו-`ofir90`. הם רשומים כרגע ב-`PLANNED_FIGURE`
   ב-`lib/life/runtime/art.ts` ולא ב-`FIGURE`, כדי שהמשחק לא יבקש קובץ שלא קיים.
   אחרי ההעלאה: להריץ `python3 scripts/life/index-sheets.py` (או לבקש ממני) ולהעביר
   את השמות חזרה ל-`FIGURE`.

- **התנגשות אמיתית לפני ש-15:10 מגיע.** שש הזדמנויות פתוחות בו-זמנית במקומות שונים,

  הקיוסק עם עיתון, אפי במגרש ונעלם בשתיים.
