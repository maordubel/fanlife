# הרקעים של שנות ה-80 — החלה

## מה יש כאן
- `public/life/art/` — 6 רקעים בשמות המדויקים שהמנוע טוען:
  - `ground.png`  — בלומפילד מבחוץ, פריים רחב (כרטיס הגעה חדש)
  - `gate7.png`   — הקרוסלות / שער 7 (מחליף את הקיים)
  - `stand.png`   — היציע מעל הדשא (מחליף את הקיים)
  - `ussExt.png`  — אולם אוסישקין מבחוץ (לא היה לו מסך עד עכשיו)
  - `ussHall.png` — אולם אוסישקין, המשחק (לא היה לו מסך)
  - `ussHallPre.png` — אולם אוסישקין, החימום (כרטיס הגעה)
- `lib/life/world/scenes.ts` — 2 סצנות חדשות (`ussishkin-outside`, `ussishkin-hall`),
  פתח כניסה "לאולם אוסישקין" מהרחוב, וכרטיס הגעה `ground` לבלומפילד.
- `lib/life/types.ts` — 2 לוקיישנים חדשים ב-`LocationId`.

## איך מחילים (על הריפו הרץ — זה שיש בו `public/` ו-`package.json`)
1. פורסים את התיקיות מעל הריפו (מדרוס גם קיימים).
2. `python scripts/life/index-sheets.py`   ← מרענן את המניפסט של הנכסים
3. `npm run build && npx vitest run`         ← אם משהו אדום — שלח לי, אני מתקן
4. פוש ל-GitHub (Vercel בונה מזה — בלי פוש, לא רואים כלום)
