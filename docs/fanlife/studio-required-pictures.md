# Football Stories: selected pictures

Owner requirement, 5 November 2026: every manually uploaded picture and every supported image in an explicitly selected Drive folder must appear in the documentary.

The new-film form uploads the full validated batch while the job is held, records the private-storage manifest, then resumes. Files added to an existing job require a stopped worker. Content-derived storage names preserve distinct pictures even when their original filenames coincide or use Hebrew/Greek. Invalid files, failed PUTs, missing downloads and undecodable required pictures stop with a named error. Nothing silently drops out of the selection.

An explicit Drive folder is rescanned directly, recursively, on every attempt, independently of the root library inventory. Its images bypass relevance filtering and the optional library's top-N limit. An incomplete, inaccessible or unverifiable public listing stops the job. This public-folder reader needs “Anyone with the link” sharing; an empty/unreadable subfolder cannot be distinguished reliably and must be removed from the selected pack or made readable before retrying. PNG, JPEG, WebP and HEIC are supported on the production runner (HEIC requires its existing pillow-heif installation).

The per-job manifest carries source IDs, original names, descriptions, optional cached visual tags and the required flag through ingestion, writer, edit and QA. General library matching uses complete club identities, story words and years across project boundaries, including THE WORKER for Hapoel Tel Aviv. Optional visual analysis uses the existing Gemini connection, describes visible content only and never creates historical claims. Missing model access does not prevent required-image placement.

The deterministic editor fills suitable illustration slots, then inserts four-second shots for any remaining selections. Existing narration and data cards survive; voice offsets, shot IDs and chapter times move together. Extra time is reported rather than fitting extra pictures into unreadable flashes. Classic, VOX and HyperFrames preserve the entire selected picture with letterboxing when needed and retain existing club colour rules. Required-art errors cannot enter the generic-art fallback. Render receipts and `media-usage.json` identify each picture and its shot timings; QA rejects missing receipts or sources. A changed manifest invalidates downstream render/mix/package checkpoints while retaining script and voice caches.

This contract applies to Football Stories documentaries. CLASSIFIED and I WAS THERE retain their separate series-specific media inputs; the documentary upload control is not offered on those jobs.

Validation: `test_required_media.py` exercises selected folders above 60 images, incomplete scans, missing downloads, filename collisions, resume ingestion, scene placement, narration timing, whole-picture framing, render receipts and actual selected pixels in classic/VOX frames. `stories-pictures.test.ts` covers batch validation, storage names, complete upload registration and worker pause acknowledgement. The existing studio, HyperFrames and admin suites remain required.
