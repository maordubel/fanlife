# FAN LIFE — חבילת מחקר ארבעה מועדונים

התחלה: `FANLIFE-RESEARCH-HE.md`, ואחריו תיק המועדון הרצוי בתיקיית `dossiers`.

חבילת מחקר לבדיקה; אינה ארכיון היסטורי ממצה ואינה מאגר ייצור מאושר. המחקר החדש והמאגר הקיים של פנאתינייקוס מסומנים בנפרד. JSON ו־CSV שומרים את המקורות ואת גבולות הכיסוי.

קובצי `existing-staging/panathinaikos` נשמרו מהמאגר הקיים של המשתמש. קובצי `discovery` הם אינדקס מסמכים בלבד. `coverage.json` מציג ספירות ו־`validation-report.json` מציג בדיקות מבנה.

אין להעתיק ישירות ל־core.json: נדרשים מתאם, מיפוי זהויות, הכרעת סתירות ובדיקת ה־compiler. כל שדה חסר נשאר חסר. דירוגים, מחירים וזכויות מדיה לא הומצאו.
