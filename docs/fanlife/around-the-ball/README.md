## The rules a script meets

1. **Every claim has a numbered source** under the script; two publishers for anything a name hangs on.
2. **Where sources disagree, both versions are told and named** ("Version A · Version B"). Never pick the dramatic one quietly.
3. **What the owner's brief said and the sources did not support is listed under "What the fact-check changed"** — kept, not deleted, so nobody puts it back.
4. **Hook laws** (writers' room §3): line one is a concrete thing in a concrete place and time; no "did you know", no hype words, no exclamation marks in the narration.
5. **Heavy stories (ATB 09 · Zambia) are told HEART-quiet**: no shout words, no music stings on the crash, names of the dead said with care.
