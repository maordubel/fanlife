# Gates opened from UEFA's own records (10.10.2026)

**Owner decision (chat, 10.10.2026): UEFA is sufficient for its own competitions.** Date, teams, score, scorers and starting elevens of a European tie are approved on UEFA's match record alone. Applies to European matches only; a domestic fact still needs its own sources.

What it changed
- `scripts/ingest/clubs/wave.ts`: a UEFA-only match is `approved` (confidence 2, `approvedBy` quotes the decision) and carries `lineup`, `bench`, `scorers` at top level, so the Historical Line-up gate reads them.
- `lib/clubs/euro-wave.ts` (`withEuro`, called by every club provider): a club plays one match a day, so a UEFA match is the same match as a pack match on that date. A pack record with no eleven is filled from UEFA (source added); a UEFA match the pack lacks is added; a pack eleven is never overwritten.
- `scripts/ingest/clubs/uefa-mysteries.ts` (`club-packs/<club>/wave-mysteries-2026-10-10.json`): Blind Cow targets from the line-ups of the latest 100 European ties — Nationality, Position, European tie (competition and season named), Birth month, Height, Shirt number (with its season). Target = exact normalised name matching exactly one pack player (rule 7); fewer than five clues = no mystery; the name never appears.
- `npm run club:wave -- --club <id>` and the mysteries script run with `NODE_USE_ENV_PROXY=1` in this sandbox.
