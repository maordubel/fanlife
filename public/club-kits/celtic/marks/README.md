# Celtic 2024/25 home illustration

`dafabet-2024-illustrated.svg` is a newly drawn approximation of the shirt sponsor, not an official logo file. The shirt geometry is an illustration based on the existing colours-of-football catalogue image (`sco_celtic_1_2425.png`) and the [Celtic FC home kit announcement](https://de.store.celticfc.com/en/pages/home-kit-24-25). The club crest is the existing repository asset. The sponsor mark, collar detail, fabric and the kit as a whole are not claimed to be exact replicas.
